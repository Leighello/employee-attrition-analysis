# Employee Attrition Analysis

A data analytics project that explores the key factors associated with employee attrition using Python. The objective is to identify the key factors associated with employee turnover and provide data-driven recommendations to improve employee retention.

---

## Project Objective

This project answers the following business questions:

- What is the overall employee attrition rate?
- Which employee characteristics are associated with higher attrition?
- Does monthly income influence employee attrition?
- Does working overtime increase employee attrition?
- How does job satisfaction relate to employee attrition?
- Which departments and job roles experience the highest attrition?
- What recommendations can help reduce employee turnover?
